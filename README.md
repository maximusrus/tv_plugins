# TV plugins

## Lampa → qBittorrent

[qbittorrent.js](qbittorrent.js) добавляет пункт **«В qBittorrent»** в меню
долгого нажатия **ОК** на раздаче. Постоянной кнопки в карточке нет.

Поддерживает magnet и HTTP(S)-ссылки на торрент, в том числе ссылки загрузки
без расширения `.torrent`. Сначала ищет готовый magnet, затем URL в полях
`Link`, `link`, `downloadUrl`, `DownloadUrl` и magnet-полях.

### Установка

1. Отключите старый плагин `kostya4000/lampa-qbit`, чтобы не было двух обработчиков.
2. Добавьте в расширениях Lampa:
   `https://maximusrus.github.io/tv_plugins/qbittorrent.js`.
   Используйте именно GitHub Pages: адрес `raw.githubusercontent.com` отдаёт
   `text/plain` с `nosniff`, поэтому WebView блокирует выполнение скрипта,
   даже если проверка доступности в Lampa показывает HTTP 200.
3. Перезапустите Lampa. Откройте **Настройки → qBittorrent** и задайте адрес Web UI,
   логин и пароль. Обход авторизации включайте только если он уже настроен на сервере.
4. Нажмите **Проверить подключение**: должно появиться сообщение с версией qBittorrent.
5. Откройте список раздач, удерживайте **ОК** на нужной раздаче и выберите **В qBittorrent**.

Настройки прежнего плагина (`qbit_*`) сохраняются. При первой установке адрес,
логин и пароль пустые; обход авторизации выключен. В репозитории нет личных
настроек сервера. Путь сохранения задаётся в файловой системе qBittorrent,
для Docker — внутри контейнера.

### Загрузки и подтверждение

В боковом меню появился **qBittorrent**: название, статус, прогресс, скорость
и оставшееся время. Незавершённые загрузки идут первыми. Экран обновляется
каждые 5 секунд, пока открыт; есть кнопка **Обновить**. При ошибке старые данные
остаются с предупреждением. Нажмите **ОК** на раздаче для действий:
**Удалить торрент** сохраняет файлы, **Удалить торрент и файлы** удаляет их
с диска. Оба действия требуют отдельного подтверждения с названием раздачи;
по умолчанию выбрана отмена. Плагин проверяет исчезновение торрента из списка,
но факт удаления файлов с диска не может проверить через этот ответ API.

При включённой настройке **Проверять добавление** плагин сначала читает список
загрузок, затем проверяет появление раздачи до 10 раз с интервалом 2 секунды.
Сообщение показывает **Добавлено** или **Уже добавлено**, статус и прогресс.
После подтверждения можно открыть список загрузок. Для magnet используется
infohash, для нового API — возвращённый ID. Пока HTTP-ссылка ещё обрабатывается
и ID отсутствует, проверяется новая раздача с точным названием, заданным
плагином. Без переименования и без ID подтверждение может остаться неизвестным:
плагин предлагает проверить список и не отправляет запрос повторно.

### Папки фильмов и сериалов для Jellyfin

В **Настройки → qBittorrent** задайте **Папка для фильмов** и **Папка для сериалов**.
Можно указать имя подпапки (`Movies`, `Shows`) относительно базового пути
или полный путь, видимый серверу qBittorrent. Для относительного пути базовая
папка обязательна. Jellyfin должен читать эти же
каталоги через свои библиотеки (пути внутри контейнеров могут отличаться).
Тип определяется по карточке Lampa, а не по названию раздачи. Выбранные серии
попадают в папку сериалов так же, как сезон целиком.

Если отдельный путь задан, он используется без добавления категории, с отключённым
автоуправлением путём qBittorrent; сама метка категории сохраняется. Если поле
пустое или тип карточки неизвестен, действует прежняя настройка базового пути
и категории. Уже добавленные торренты не перемещаются. Настройка не создаёт
библиотеки Jellyfin и не меняет структуру файлов внутри раздачи.

### Прямой переход из карточки

В **Настройки → qBittorrent → Смотреть → Торренты** можно включить прямой
переход к раздачам по кнопке **Смотреть** в карточке фильма или сериала.
По умолчанию переключатель выключен. Изменение действует без перезапуска;
выключение возвращает обычное меню источников. Если торренты недоступны
для карточки, откроется обычное меню. Сам переход ничего не скачивает.

### Статусы карточки и Jellyfin

Проверка Jellyfin по умолчанию выключена. Чтобы включить её, активируйте
**Проверять библиотеку Jellyfin** и заполните **Адрес Jellyfin** и **Токен доступа Jellyfin**
в настройках qBittorrent. Токен хранится в настройках Lampa на устройстве. Для
проверки можно использовать токен пользователя с доступом к нужным библиотекам
или создать ключ API в панели администратора Jellyfin. Не добавляйте токен в
исходный код и не передавайте его посторонним.

Карточка TMDB показывает состояние Jellyfin и статус подтверждённой загрузки.
Плагин связывает торрент с карточкой после подтверждения добавления по его хешу;
старые раздачи, добавленные до этой функции, автоматически не сопоставляются.
При ошибке подключения или неоднозначном совпадении статус отсутствия не
выводится. Серии сопоставляются по TMDB ID сериала и номерам сезона и серии.

### Выбор серий / файлов

Для фильма **В qBittorrent** сразу отправляет раздачу целиком. Для сериала
или карточки неизвестного типа можно выбрать **Выбрать серии / файлы** или
**Скачать целиком**. В списке файлов более поздние сезоны и серии показаны
сверху: имена сортируются по убыванию с учётом чисел (10 перед 2). Файлы с распознанными
номерами показаны как S02E06; полное имя доступно в описании. Кнопка **Выбрать
последнюю серию** отмечает самый поздний распознанный видеофайл, но не начинает
скачивание. Неоднозначные имена остаются под исходным названием.
Для выбора файлов нужен qBittorrent 5.3 или новее: `fetchMetadata` получает
метаданные отдельно, без добавления раздачи в загрузки и без скачивания серий.
Ожидание ограничено 60 секундами; после таймаута можно повторить попытку.
Отметьте нужные файлы кнопкой ОК, затем нажмите **Скачать выбранные**. Ничего
не выбрано заранее; отмена не добавляет торрент. Файлы показаны исходными
именами, чтобы можно было различить серии, дорожки и субтитры.

В запрос добавления передаётся полный массив `filePriorities`: 1 для выбранных
файлов, 0 для остальных. При недоступном API, таймауте или устаревших метаданных
весь сезон автоматически не запускается. Если торрент уже добавлен, плагин
сообщает об этом и не изменяет его приоритеты. Magnet требует доступных пиров
для получения метаданных. Из-за общих частей торрента клиент может сохранить
небольшие фрагменты соседнего невыбранного файла.

### Как работает

- Запросы идут через штатный `Lampa.Reguest.native`: на Android — нативный HTTP,
  в браузере — AJAX с cookies. Сервер должен быть доступен с телевизора.
- Поддерживаются старый ответ `Ok.` и пустой HTTP 204 при входе в новых версиях.
  После входа проверяется авторизованный доступ к API версии. Для нативного
  клиента Android также передаётся HTTP Basic Authorization (qBittorrent 5.3),
  а session cookie сохраняется только в памяти плагина: получение метаданных
  и добавление выбранных файлов используют одну сессию.
- Ссылка передаётся в `/api/v2/torrents/add` как multipart-поле `urls`.
  Категория, путь и переименование поддерживаются; загрузка запускается после
  выбора «Скачать целиком» или «Скачать выбранные».
- HTTP-ссылку скачивает **сам сервер qBittorrent**. Ему нужен доступ к индексатору;
  `localhost` в такой ссылке означает сервер qBittorrent. Ссылки на HTML-страницы,
  требующие cookies телевизора или истёкшие токены, могут не сработать.
- Обрабатываются JSON-ответы новых версий: добавление, ожидание загрузки
  торрент-файла и ошибка. Для старого ответа `Ok.` и magnet с 40-значным hex
  infohash доступна проверка списка. Подтверждение добавления не означает
  завершённую загрузку. Поле Lampa `hash` не используется как infohash.
- При таймауте нет автоматической повторной отправки: сначала проверьте список
  загрузок. Ошибки авторизации и некорректного торрент-файла показываются отдельно.

В обычном браузере возможны ограничения CORS / mixed content. Плагин не обходит
защиту Web UI и не выдаёт непрочитанный ответ `no-cors` за успешную загрузку.

### Проверки

Node.js 18+; установка зависимостей не требуется:

```sh
npm run check
npm test
```

Тесты проверяют меню, выбор ссылок, запросы, ошибки, таймауты и подтверждение
через mock API Lampa. Они не заменяют проверку на телевизоре и реальном qBittorrent.
